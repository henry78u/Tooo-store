# TOOO STORE — Feature and Data Inventory Matrix

## 1. Feature Classification Legend

Each feature discovered in the TOOO STORE codebase is classified into one of the following implementation statuses:
1. **[MOCK/LOCAL]**: Implemented in the frontend with mock data or browser `localStorage` state.
2. **[PARTIAL]**: Partially implemented; UI components and client workflows exist, but full lifecycles require server coordination.
3. **[API-CONNECTED]**: Connected to a live backend API (currently none; Vite SPA runs client-side).
4. **[MISSING]**: Feature referenced or implied by UI/architecture but missing implementation.
5. **[AMBIGUOUS]**: Requires an explicit business or product decision before implementation.
